Obstacle Detection Radar Using Ultrasonic Sensor

1. Project Overview

This project demonstrates a simple radar system using an Arduino Nano, ultrasonic sensor and servo motor. It detects nearby objects and displays their positions on a laptop screen using a radar-like graphical interface.

2. Aim

To design and develop a low-cost radar system that detects and displays the position of objects within a certain range.

3. Components Used

- Arduino Nano
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- Laptop
- Processing IDE
- Breadboard
- Jumper Wires
- USB Cable

4. Working Principle

1. The ultrasonic sensor sends sound waves.
2. The waves reflect after hitting an obstacle.
3. The sensor receives the reflected waves.
4. Arduino calculates the distance.
5. The servo motor rotates the sensor from 0° to 180°.
6. Distance and angle data are sent to the laptop.
7. Processing IDE displays the detected objects on a radar screen.
